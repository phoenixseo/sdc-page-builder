# Screenshots

`readme.txt` currently ships **no** screenshots — the `== Screenshots ==` section
says so in plain words instead of listing captions whose files do not exist.

These four shots are the intended set. Store them in this directory, named
`screenshot-1.png` … `screenshot-4.png` (wp.org's convention; it maps the numbers
to the order of the list in `readme.txt`):

1. The inserter: *SDC components* at the top, one block per component type.
2. A component in the canvas, rendered with the real frontend markup.
3. The selected component's fields in the block sidebar.
4. The component catalogue in the admin: fields, usage count, and the delete guard.

When the files exist, put the four captions back into the `== Screenshots ==`
section of `readme.txt` in that order. Until then the section must not list
numbered items: a caption without a file is a review finding.

Recommended size is 1280×960 or larger, PNG. Keep personal data (user names,
real client content) out of the frame.
